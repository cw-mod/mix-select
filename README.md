# CatWar: быстрое выделение предметов для смешивания

Быстрое выделение предметов во рту на игровой странице `/cw3` на **catwar.su** и **catwar.net** — вместо клика по каждому предмету.

## Скачать

- [mix-select.user.js](https://cw-mod.github.io/mix-select/mix-select.user.js) — юзерскрипт для Tampermonkey.
- Страница мода: https://cw-mod.github.io/mix-select/

## Установка (Tampermonkey)

1. Установите [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте [mix-select.user.js](https://cw-mod.github.io/mix-select/mix-select.user.js) и подтвердите установку.
3. Зайдите на `https://catwar.su/cw3` или `https://catwar.net/cw3`.

Скрипт обновляется сам: Tampermonkey проверяет `@updateURL` ([mix-select.meta.js](https://cw-mod.github.io/mix-select/mix-select.meta.js)) и качает новую версию с `@downloadURL`.

## Что делает

- **✚ Всё** — кнопка у блока «Смешивать»: входит в режим смешивания и выделяет все предметы сразу.
- **→ В смешение** — входит в режим смешивания, **сохраняя текущее выделение** (после Ctrl+кликов или обычных кликов по предметам).
- **✖ Снять** — снимает выделение со всех предметов.
- **Ctrl+клик** (⌘ на Mac) по предмету — выделить все предметы этого же типа сразу в режиме смешивания.

## Совместимость с «CatWar: предметы во рту» (Рецепт)

Если стоит мод [mouth-tools](https://cw-mod.github.io/catwar-mouth-tools/), Ctrl+клик отдан ему (его «галка на весь тип» без режима смешивания). Смешивание выделенного тогда делается так: Ctrl+клик по нужным типам → кнопка **«→ В смешение»** → игровая «Смешать». Панель не наезжает на плавающее окно «Рецепт».

Само смешивание скрипт не подтверждает — после выделения игрок сам нажимает игровую кнопку «Смешать». Заблокированные предметы не выделяются, коты во рту игнорируются.

## Как это работает

Выделение для смешивания в игре — это флаг `isActive` у предмета в состоянии Vue. Скрипт меняет его напрямую (игра сама подсвечивает предметы классом `active_thing`), поэтому встроенное «Смешать» видит выделение как после обычных кликов. Античит на предметы и смешивание не распространяется.
