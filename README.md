# CatWar: быстрое выделение предметов для смешивания — мод упразднён

> **Функционал этого юзерскрипта был вынесен в другой юзерскрипт — [CatWar: инструменты для рта (mouth-tools)](https://cw-mod.github.io/catwar-mouth-tools/)**, начиная с версии 2.0.0. Этот репозиторий больше не обновляется, GitHub Pages отключён.

## Что сделать

1. Удалите этот скрипт из Tampermonkey.
2. Установите **[CatWar: инструменты для рта](https://cw-mod.github.io/catwar-mouth-tools/mouth-tools.user.js)** — там есть быстрое выделение типов, «Выбрать всё»/«Снять», чердак с закреплением 🔒 и сортировка.

Последняя версия этого мода — 1.1.1 (архив, для истории): [mix-select.user.js](https://github.com/cw-mod/mix-select/raw/main/mix-select.user.js).
