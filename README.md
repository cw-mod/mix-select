# CatWar: быстрое выделение предметов для смешивания — ⚠️ мод влит в «инструменты для рта»

> **Этот мод больше не развивается.** Все его функции (кнопки смешивания, Ctrl+клик по типу, режим смешивания с сохранением выделения) влиты в мод **[CatWar: инструменты для рта](https://cw-mod.github.io/catwar-mouth-tools/)** начиная с версии 2.0.0 — вместе с чердаком, закреплением типов 🔒 и сортировкой.

## Что сделать

1. Удалите этот скрипт из Tampermonkey.
2. Установите **[mouth-tools v2.0.0+](https://cw-mod.github.io/catwar-mouth-tools/mouth-tools.user.js)**.

Архивная версия (1.1.1) остаётся здесь для истории: [mix-select.user.js](https://cw-mod.github.io/mix-select/mix-select.user.js).
