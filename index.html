CatWar: быстрое выделение предметов для смешивания

Быстрое выделение предметов во рту на catwar.su и catwar.net: не нужно кликать по каждому предмету для смешивания.

Скачать юзерскрипт

Версия 1.0.0. Юзерскрипт для Tampermonkey. Автообновление: mix-select.meta.js.

Установка

  1. Установите Tampermonkey.
  2. Нажмите «Скачать юзерскрипт» — Tampermonkey предложит установку.
  3. Откройте игровую https://catwar.su/cw3 или https://catwar.net/cw3.
  4. После установки скрипт сам обновляется с этой же страницы GitHub Pages.

Что делает

  • ✚ Выбрать всё — кнопка у блока «Смешивать»: входит в режим смешивания и выделяет все предметы сразу.
  • ✖ Снять — снимает выделение со всех предметов.
  • Ctrl+клик (⌘ на Mac) по предмету — выделить все предметы этого же типа.

Само смешивание скрипт не подтверждает: после выделения вы сами нажимаете игровую кнопку «Смешать». Заблокированные предметы не выделяются.
